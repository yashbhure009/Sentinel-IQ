# SentinelIQ

SentinelIQ is a planned security intelligence platform for policy Q&A, security finding mapping, and framework-based audits.

Planned modules:

- `backend/rag/` — policy retrieval, LLM integration, and coverage checks.
- `backend/graph/` — finding ingestion, ontology mapping, and scan data.
- `backend/audit/` — audit evaluation and remediation suggestions.
- `frontend/` — dashboard, audit, and pricing pages.
- `docs/` — API contracts, architecture, and the product demo script.

This repository currently contains starter structure and placeholder files only.
